# =============================================================================
# QUICK SETUP (Run these commands in order)
# =============================================================================
#
# 1. Install Python dependencies:
#    pip install -r requirements.txt
#
# 2. Install Ollama (download from https://ollama.ai):
#    Windows: Download and run installer from https://ollama.ai/download
#    Linux:   curl -fsSL https://ollama.ai/install.sh | sh
#    Mac:     brew install ollama
#
# 3. Pull required LLM models (run in terminal):
#    ollama pull phi3.5
#    ollama pull llama3.2
#
# 4. Start Ollama server (keep running in background):
#    ollama serve
#
# 5. Install Node.js dependencies for UI:
#    cd user-interface
#    npm install
#
# 6. Run the app:
#    Terminal 1: python api.py          (starts backend on port 8000)
#    Terminal 2: cd user-interface && npm run dev  (starts UI on port 5173)
#
